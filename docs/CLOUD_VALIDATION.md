# E2B 云端验收

从项目根目录执行：

```sh
dart run tool/cloud_smoke.dart
```

通过运行环境提供 `E2B_API_KEY`。不要将密钥写入源码、提交或测试报告。
脚本会创建一个最长两分钟的沙箱，可能产生 E2B 费用；结束时在 finally 中尝试 kill。
如果创建请求已到达云端但客户端没有收到结果，客户端可能无法获得 ID 来主动删除；
此时依靠服务端超时，并应在控制台检查残留资源。

验收项目：创建、健康、信息查询、二进制文件上传/下载、文件流、命令及输出回调、删除。
输出为 JSON，仅列成功检查名、失败阶段和异常类型，不包含凭据或异常正文。
退出码 0 表示本次全部检查及清理通过；1 表示失败；78 表示缺少凭据、没有执行。

这是一组核心云端 smoke 检查，不能代替 PTY、监听、Secrets、Volume 挂载/持久化、
模板构建及各目标平台的完整验收。CI 不自动执行，避免无意创建云资源。
