# E2B Dart/Flutter SDK 推进看板

更新时间：2026-10-13。目标为官方 `e2b` JS SDK 2.55.0 的等价移植，以 Dart/Flutter 环境下可用为准，
参考提交 `df6c368152b067512702fc677952c0fc4e13c2f0`。

## 当前验收范围（用户于 2026-10-12 调整）

核心能力、服务端请求/响应协议、默认值、认证、错误、取消及流式传输应保持等价；公开入口允许采用 Dart 的类型、Future、Stream、扩展方法和客户端生命周期表达。平台能力限制应明确说明并提供适用的实现或用法。

URL 经标准解析后含义相同但字节不同、JS 专属类型和 Fetch 的禁用方法等差异，作为语言/运行时适配记录；仅在影响服务端协议、签名或实际调用时阻塞交付。现有逐项差分证据继续保留，不再以复刻全部 JS 运行时细节为完成前提。

仍需完成：实际缺失能力的适用性审计和实现、公开面清单闭环、Dart/Flutter 目标验证、真实 E2B 联调及可发布打包。当前尚无这些验收的完整证据，不能认定完成。

## 完成度口径

采用验收等级，而非未经完整清点的百分比：

- **L0 待实现**：尚无实现。
- **L1 已实现**：代码存在，模块验证不充分。
- **L2 已有验证**：已有单元、协议或差分测试，仍有已知差异或未审计范围。
- **L3 等价审计通过**：适用公开能力、协议、参数、默认值、错误及边界行为逐项有证据，Dart 适配差异明确记录。
- **L4 交付验收通过**：L3 加上该模块适用的平台和真实服务端验证。

等级不是线性百分比。当前没有任何模块被认定为 L3/L4，不能报告总体完成百分比。
`exports.json` 新增 163 个顶层导出（113 个仅类型导出），163 个导出已建立部分映射；所有顶层导出都有对应形式，但仍需逐项完整验收；
`parity.json` 是方法候选清单，状态存在滞后，并未覆盖类型、getter、重载和传输行为；不能作为百分比分母。
